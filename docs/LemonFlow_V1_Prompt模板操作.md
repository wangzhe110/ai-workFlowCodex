# LemonFlow V1 Prompt 版本管理操作

此页管理的是**系统级 Prompt 模板**：它规定模型如何执行“参考视频分析、故事生成、角色/场景设计、导演分镜、图片提示词组织、关键帧提示词组织、视频 Prompt 生成”等固定业务操作。

它不管理项目产物。某个镜头的 `video_prompt_versions`、已审核关键帧和已经生成的视频片段仍属于项目生产记录；切换这里的模板版本不会覆盖它们。

## 打开 Prompt 中心

在浏览器访问：`http://127.0.0.1:5173/prompt-templates`，或从“模型中心”点击“Prompt 模板”。

页面按视频理解、文本创作、图片提示词和视频提示词分组显示每个业务操作。每张卡片会显示：

- Prompt 名称与稳定 `prompt_key`；
- 对应模型槽位；
- 当前活动版本及内容哈希短码；
- 草稿数量和全部历史版本。

页面不会显示 API Key、鉴权 Header、Base URL 或供应商原始配置。

## 推荐修改流程

1. 选择要调整的业务操作，阅读当前活动版本和允许变量。
2. 点击“复制活动版为草稿”。旧版本始终保留，系统不会原地覆盖已发布正文。
3. 只编辑草稿的“系统 Prompt”“用户 Prompt”和“变更说明”。
4. 只能插入页面列出的简单变量，例如 `{selected_story}`。不要写 `{product.name}`、`{items[0]}`、函数、Jinja 语法或表达式。
5. 在“安全测试变量”中填写不含真实素材、密钥或链接的 JSON 对象，点击“仅渲染预览”。此操作只在服务器本地渲染，不会调用模型、不会创建任务，也不会产生费用。
6. 查看“版本文本差异”，确认本次正文变化符合预期。
7. 点击“保存草稿”，确认后点击“发布草稿”。发布后正文变为只读。
8. 点击“启用/回滚到此版本”。启用是显式操作，不会自动替换任何生产任务；回滚只是重新指向一个历史已发布版本。

## 变量与安全限制

- 每个业务操作的变量和输出契约都由后端代码固定。页面不能新增变量，也不能修改 JSON 解析规则。
- 必填变量缺失、未知变量、复杂占位符、URL、鉴权信息、Cookie、密钥字段或 `data:image/...;base64,` 都会被拒绝。
- 项目输入会被放入明确的 `LEMONFLOW_INPUT` 边界中，并以安全 JSON 形式渲染；本机路径、签名 URL、模型配置和鉴权元数据不会送进 Prompt。
- `FINAL_COMPOSE` 是本地 FFmpeg 合成，不使用模型，因此没有 Prompt 模板。

## 版本和运行冻结规则

- Draft 可编辑；Published 版本不可编辑。
- 发布不等于启用；只有启用后，**之后新创建的任务**才会使用该版本。
- 创建 WorkflowRun/WorkflowStep 时，系统会冻结 `prompt_key`、目录 ID、版本 ID、版本号、内容哈希、系统/用户模板哈希、允许变量、输出契约、变量摘要和渲染哈希。
- Worker 只读取这份冻结快照，绝不会执行时重新查询当前活动 Prompt。
- 因此切换 Prompt 后，已经创建、正在运行或恢复已有供应商任务的历史记录不会改变；恢复也不会重新渲染或重新提交供应商任务。
- 项目“生产追溯”页只显示本次调用的 Prompt 名称、版本和哈希短码，不显示系统 Prompt 正文。

## 常见提示

| 提示 | 含义与处理 |
| --- | --- |
| `Prompt 缺少必填变量` | 检查预览 JSON 是否补齐当前版本列出的必填变量。 |
| `未知或不合法变量` | 只使用页面给出的 `{simple_name}` 变量。 |
| `已发布 Prompt 不可编辑` | 从该已发布版本复制一个 Draft，再编辑。 |
| `只能激活已发布 Prompt 版本` | 先发布草稿，再显式启用。 |
| `活动版本无效` | 不要用旧任务继续生成；请联系技术人员检查 Prompt 中心数据完整性。 |

不要把真实 API Key、Cookie、Authorization、完整签名 URL、Data URL、未授权剧本或原视频内容复制到 Prompt 中。
