# 云雾视觉视频分析接入说明

“参考视频分析”的画面节点支持 `openai_compatible_vision` 适配器。它不把整个本地
视频文件直接上传到中转站：后台 Worker 使用 FFmpeg 从视频中均匀抽取 1–12 张 JPEG
帧，再通过 OpenAI 兼容的视觉 Chat Completions 请求发送给已配置的模型。若同时启用
语音转写节点，视觉模型会在同一次内存请求中参考临时转写文本；原文不写数据库或前端。

模型只允许输出抽象创作机制：开头的信息释放、人物目标/阻碍类型、冲突、节奏和
悬念功能。系统提示与结果契约禁止保存或建议复用原视频的具体人物、台词、屏幕
文字、音乐、画面和情节；帧只在 Worker 内存中使用，不写数据库、不返回前端。

## 1. 部署前提

1. Worker 所在系统必须安装 `ffmpeg` 和 `ffprobe`，并可从命令行访问。
2. 开发默认以本地 `LOCAL_STORAGE_PATH` 保存参考视频，因此执行 Worker 必须挂载
   同一个素材目录。生产可设置 `SOURCE_VIDEO_STORAGE_MODE=s3`，Worker 会从已配置
   的 S3/MinIO 下载受限临时副本，再执行 FFmpeg/FFprobe；临时副本不保留。
3. 在未提交的 `.env` 或部署密钥管理器中设置 `YUNWU_API_KEY`，重启后端/Worker。
4. 所选模型必须同时支持图片输入和 JSON 输出；模型名以云雾账户当前模型列表与
   文档为准。

## 2. 配置中心填写方式

选择“参考视频分析”，页面会预填以下类型：

| 字段 | 值 |
| --- | --- |
| 供应商标识 | `openai_compatible_vision` |
| 模型标识 | 云雾后台实际视觉模型名 |
| API 地址 | `https://yunwu.ai/v1` |
| 密钥环境变量名 | `YUNWU_API_KEY` |
| 抽帧数量 | 建议从 6 开始，可填 1–12 |
| 单帧提取超时 | 建议 120 秒，可填 5–300 秒 |
| 单帧请求体上限 | 建议 2,097,152（2 MiB），可填 64 KiB–8 MiB |

每次启动分析都会冻结该模型配置。后续切换模型、抽帧数量或温度，不会改变已有
分析结果。抽帧会统一缩放到 768px 宽并受单帧字节上限保护，避免 4K 视频意外产生
超大多模态请求。`vision_request_options` 可填写模型文档明确支持的非敏感参数；不得覆盖
`model`、`messages`、`response_format` 等平台控制字段。

## 3. 验收与故障排查

- 先以一个已授权的小视频测试，确认任务依次经过抽帧、视觉模型调用和结果保存。
- “需要安装 ffmpeg, ffprobe”表示 Worker 镜像/主机缺少系统依赖。
- “无法读取参考视频时长”或“抽帧失败”通常说明视频文件损坏、编码不支持，或
  Worker 没有读取本地素材目录的权限。
- 若模型返回非 JSON 或缺少规定字段，任务会标记失败；更换支持 JSON 的视觉模型，
  或在其官方文档允许的范围内调整扩展参数。
- 上线前评估不同视觉模型的成本、时延、抽象结果质量和合规性，确认它不会把原作
  的具体表达带入后续原创流程。
- 音频转写模型的独立配置、数据边界和验收方式见 `云雾语音转写接入说明.md`。
