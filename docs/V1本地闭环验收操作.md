# LemonFlow V1 本地闭环验收操作

这份说明用于在**不配置任何模型 Key、不花费模型额度**的情况下，检查 V1 的页面、审核节点和数据流是否正常。

## 你会看到什么

系统会显示“本地模拟”生成的分析、故事、角色图、场景图、关键帧和视频片段。它们用于检查流程，**不是真实 Gemini、Claude、Banana 或 Seedance 的结果，也不能用于发布生产内容**。

## 操作步骤

1. 启动后端和前端，浏览器打开项目首页。
2. 点击“创建并进入工作台”，填写一个项目名称即可。
3. 上传一个你有权用于测试的视频文件。
4. 在“当前等待什么？”区域点击“开始视频分析”。
5. 在下方打开分析结果，检查创作简报后点击“确认并锁定创作简报”。
6. 点击“并行生成原创故事方案”，从三份方案中选择一份。
7. 点击“生成角色资产与参考图”，逐个点击“锁定此角色图版本”。所有角色都锁定后，系统会自动进入场景阶段。
8. 点击“生成场景资产与参考图”，逐个锁定场景图。
9. 点击“生成 AI 导演分镜”，再点击“生成分镜关键帧”，逐个锁定关键帧。
10. 点击“生成视频片段”，逐个点击“通过此视频片段”。
11. 当页面显示“合成成片”时，点击“合成完整成片”。状态变为 `COMPLETED` 即表示审核与状态流转正常。

每次锁定、选择、通过或驳回前，都可以填写“审核人”和“备注”。以后加入账号系统后，审核人会自动来自登录账号，历史记录仍会保留。

## 常见情况

- **页面提示模型 Adapter 尚未接入**：你已经把模型槽位切换到真实模型配置，但对应渠道还没有完成 V1 Adapter 验收。先切回“本地模拟”完成流程验证，或联系技术人员接入该渠道。
- **看不到真实图片或视频预览**：本地模拟结果使用 `mock://` 地址，故意不伪装成真实图片或 MP4。
- **按钮无法点击**：请看顶部的“V1 生产链路”。系统只允许在当前阶段创建对应任务，目的是防止跳过人工审核。
- **想重做已锁定结果**：不要覆盖旧版本。应该新建版本，再由角色、场景或分镜的当前采用指针选择新版本；已被视频片段使用的旧版本会永久保留。
