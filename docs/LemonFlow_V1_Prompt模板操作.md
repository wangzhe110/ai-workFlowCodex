# LemonFlow V1 Prompt 模板操作

Prompt 就是写给 AI 的工作说明。它会影响故事、图片或视频结果，因此 LemonFlow 不允许直接修改已经在生产中使用的 Prompt。

## 打开页面

浏览器打开：`http://127.0.0.1:5173/prompt-templates`。

## 日常修改步骤

1. 在“用于哪一步”选择要优化的环节，例如“原创故事生成”。
2. 修改模板名称或模板内容；不要包含 API Key、用户隐私、未授权的完整台词或参考视频原画面说明。
3. 点击“保存为新草稿版本”。原来的版本不会被改动。
4. 用小项目完成一轮测试，查看输出是否更稳定、更原创、是否符合审核要求。
5. 确认效果后，回到该用途的历史版本列表，点击“启用这一版”。

每个生产用途同时只有一个“当前生效”版本。启用新版本时，旧版本自动归档，但旧项目和旧模型调用仍保留它们已冻结的 Prompt，因此历史内容可以完整追溯。

## 变量说明要不要改？

通常不用改，保持默认的 JSON 内容即可。这是留给后续技术扩展识别可传入变量的说明，不会要求制作人员填写。只有开发人员明确要求增加变量时，才修改它。

## 归档规则

- 草稿可以归档，适合淘汰测试失败的版本。
- 当前生效版本不能直接归档。先启用同一用途的另一版，再归档旧版本。
- 归档只影响未来新任务；已经开始的任务继续使用启动时冻结的 Prompt。
