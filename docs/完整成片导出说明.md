# 完整成片导出说明

视频片段页现在支持“合成完整成片”。该功能不是简单拼接当前页面看到的任意结果，
而是按可审计规则生成一版完整视频：

1. 找到当前确认分镜最近一次**完整成功**的视频分组方案；
2. 按组号排序；
3. 每一组取与该分组范围相同的最新成功版本（因此会吸收用户对单组的重做）；
4. 将实际使用的片段 ID 固定为一版 `FinalVideo`；
5. 后续重做片段不会改写已生成的成片；再次导出才会生成新的成片版本。

## 本地模拟与真实 MP4

- 默认“本地模拟完整成片”可跑通审核、版本与任务流程，但只返回 `mock://` 占位地址，**不会假装生成可下载 MP4**。
- 要得到真实 MP4，在“模型配置中心”选择“完整成片导出”，新增并启用：

| 字段 | 值 |
| --- | --- |
| 供应商标识 | `ffmpeg_concat` |
| 模型标识 | `ffmpeg-concat-v1` |
| API 地址/密钥 | 留空，不需要 |
| 单片段下载超时 | 建议 120 秒 |
| 单片段体积上限 | 建议 500 MiB |
| 成片体积上限 | 建议 2 GiB |
| FFmpeg 合成超时 | 建议 1800 秒 |

真实模式要求所有待合成片段均有可访问的 HTTPS 视频地址。Worker 会在临时目录下载
它们，使用 FFmpeg 重新编码为 H.264/AAC MP4，并把输出保存至受项目范围保护的媒体
存储；临时下载文件在任务结束时删除。

## 用户操作

1. 在“视频片段”页面确认所有组显示“已生成”。
2. 如果某组效果不满意，点击该组“重做此组 / 新版本”，待成功后再继续。
3. 点击“合成完整成片”。
4. 等待任务显示“已完成”。
5. 在“完整成片”区域点击“下载 MP4”。如有多版，v 数字越大表示越晚导出的版本。

## 常见问题

- “请先成功生成一整套视频片段”：当前确认分镜没有一次覆盖全部镜头的成功视频运行；先点击“批量生成视频片段”。
- “视频地址返回了非视频内容”或“无法下载视频片段”：通常是第三方视频 URL 已过期、需要登录，或不是 HTTPS 公网地址；请重做对应组并检查中转站结果 URL。
- “FFmpeg 合成失败”：确认 Worker 已安装 FFmpeg，且片段视频可下载、编码兼容。必要时先用同一视频模型和相同规格重新生成该组。
- “完整成片超过上限”：在合规的资源预算内调高配置，或减少镜头/片段时长；不要无限制放大 Worker 磁盘和网络消耗。

## 生产注意事项

当前 V1 默认由 `LocalFinalVideoDelivery` 保存，适合单机验收。多实例生产部署时，
将 `FINAL_VIDEO_DELIVERY_MODE=s3`，复用 `S3_ENDPOINT_URL`、`S3_BUCKET`、
`S3_PUBLIC_BASE_URL` 和服务端 AWS/MinIO 凭据；`S3FinalVideoDelivery` 会将 MP4 流式
上传并返回稳定 HTTPS 下载地址。仍需确保执行 FFmpeg 的 Worker 有足够的临时磁盘、
带宽、超时限制和清理策略。

本步骤只解决片段排序与视频合成。字幕、配音、背景音乐、片头片尾和封面将作为
后续独立后期模块接入，避免与核心合成步骤耦合。
