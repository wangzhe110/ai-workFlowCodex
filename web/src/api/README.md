# 前端接口模块

所有浏览器 HTTP 请求集中在这里。

- `http.ts`：统一处理 API 地址、JSON 编码和可读错误。
- `projects.ts`：项目、素材上传、创作工作流，以及按镜头分组的视频片段接口。
- `creative-library.ts`：爆点元素、爆款开头等抽象创作资产的管理接口。
- `model-profiles.ts`：步骤模型配置的读取、新版本创建、无扣费预检、人工评测记录、同步骤对比和激活接口；请求中不含真实 API Key。
- `production.ts`：V1 生产状态、人工审核/锁定、模型槽位、候选模型版本与人工启用接口；不包含任何具体模型 HTTP 协议或真实密钥。

页面不得直接调用 `fetch`，这样未来增加登录 Token、请求追踪、SSE 或错误上报时只需改此目录。
