# LemonFlow V1 模型配置小白操作卡

你只需要记住：**模型按“它在流程里做什么”配置，不按某家供应商写死。** 每一项先保存候选，小样本成功后再启用。

## 不要做的事

- 不要把真实 API Key 粘到网页、Prompt、项目备注或截图。
- 不要为了换模型修改代码；在“模型中心”创建或复制配置版本即可。
- 不要直接覆盖已经产生调用记录的版本；先复制成新草稿、修改、跑样本，再人工启用。
- 不要反复点击视频生成。任务创建后会冻结配置并防重复提交。

## 每个槽位填什么

| 生产步骤 | 模型应该做什么 | 默认目标 | Adapter | 关键填写项 |
| --- | --- | --- | --- | --- |
| 视频分析 | 从视频帧提炼脚本结构、开头、爆款元素、场景、简报 | Gemini 3.1 Pro Preview | `openai_compatible_vision` | 模型名、API 地址、`secret_env_name` |
| 多模型故事 | 生成原创故事候选 | Claude Sonnet 4.6、Claude Opus 4.6、Gemini 3.1 Pro Preview | `openai_compatible` | 三个候选分别建一版并同时启用 |
| 角色设计 | 输出角色年龄、外貌、服装、气质 | 可替换文本模型 | `openai_compatible` | 模型名、API 地址、`secret_env_name` |
| 场景设计 | 输出地点、环境、风格、氛围 | 可替换文本模型 | `openai_compatible` | 同上 |
| 导演分镜 | 根据锁定角色和场景设计镜头 | 可替换文本模型 | `openai_compatible` | 同上 |
| 角色图/场景图/关键帧 | 生成图片资产 | Banana 2 | `openai_compatible_image` | 图片模型名；关键帧还要填参考图字段名 |
| 视频片段 | 根据锁定关键帧和动作生成视频 | `doubao-seedance-2-0-mini-260615` | `volcengine_ark_video` | `ARK_API_KEY`；竖屏/时长配置 |
| 成片合成 | 重新编码拼接已通过片段 | FFmpeg | `ffmpeg_concat` | 不需要模型 Key；Worker 必须有 FFmpeg |

## 最短操作步骤

1. 请负责人把真实 Key 写入服务器环境变量，例如 `ARK_API_KEY`，重启 API 和 Worker。
2. 打开“模型中心”，选择一个槽位，新建候选配置。
3. 填写模型名称、服务地址、`secret_env_name` 和非敏感参数；保存为草稿。
4. 用授权短视频跑一条小样本，记录模型、Prompt、耗时、成本和人工评分。
5. 合格后点“启用此版本”。旧任务仍会使用自己创建时冻结的旧版本。

## 想修改已经保存的模型怎么办

- **草稿版本**：可直接点“编辑此版本”。
- **已启用但尚未产生调用的版本**：仍可直接编辑。
- **已经产生调用记录的版本**：不能修改；点“复制为新草稿”，系统会创建下一版。修改、测试通过后，再手动启用新版本。

所以历史项目始终绑定旧版本；新项目或新任务才会按你手动启用的新版本执行。

## 想删除一个模型怎么办

- **未启用、未使用的候选**：可以直接删除。
- **已启用但没有任务在运行、也没有历史调用**：确认后可以删除；删除后该功能可能暂时没有可用模型，请先准备好替代版本。
- **有进行中的 V1 任务**：系统会识别任务创建时冻结的模型版本，并禁止删除，等任务结束后再处理。
- **已有历史调用或质量评估**：不能删除，避免项目追溯失效。可停用它，再复制一个新草稿继续测试。

故事生成要同时启用三份候选，才能得到三份并行方案；其他步骤通常一次只启用一个版本。详见 [真实模型配置操作](LemonFlow_V1_真实模型配置操作.md)。
