# LemonFlow V1 模型配置预检说明

“基础预检（不生成内容）”用于在花费模型额度前发现部署错误。预检不会返回 API Key，也不会写入数据库。

## 预检检查什么

- 当前槽位使用的 Adapter 是否已被系统支持；不支持的 Adapter 只能作为候选，不能启用。
- API 地址、模型标识、超时、字段映射、图片参考图字段等非敏感参数是否完整。
- `secret_env_name` 指向的服务器环境变量是否已注入；页面只显示变量名，不显示值。
- OpenAI 兼容文本、图片和视觉配置在有 Key 时可查询只读 `/models`，确认服务连通；此请求不生成内容。
- Seedance 视频配置检查 Adapter、模型名、Key 变量与参数完整性，但不提交供应商视频任务。
- 成片合成检查 API/Worker 镜像能否执行 FFmpeg/FFprobe。

## 为什么视频模型不自动联网生成测试

异步视频供应商没有统一的零费用接口。网络超时也不代表供应商没有接单，自动重复提交可能造成重复扣费。因此预检只做配置检查。通过后请用一个镜头做真实小样本，人工确认任务号、轮询、视频地址、成本与质量。

## 推荐顺序

1. 在部署密钥管理器或 `infra/backend.env` 中写入 Key，并重启 API 与 Worker。
2. 在模型中心新建候选，不要立刻启用。
3. 运行基础预检；“提示”表示仍需要小样本验证。
4. 以授权短视频验证分析、故事、角色/场景、关键帧和一个视频片段。
5. 记录成本、耗时、成功率和人工评分，再人工启用。

模型配置或 Prompt 在任务创建后发生变化，不会影响已创建任务：它们会使用自己的冻结快照。
