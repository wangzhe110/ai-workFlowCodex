# LemonFlow V1 真实模型配置操作

这份说明给第一次接触模型配置的制作负责人使用。目标不是一次把所有模型都接上，而是按顺序让 V1 的每一步都能被安全地小样本验证。

## 先记住两条规则

1. 网页里只填写“模型名称、API 地址、服务器变量名”；**绝不填写真实 API Key**。
2. 新模型先保存为“候选”，用一个测试项目跑通后才人工启用。系统不会根据价格或评分自动替换生产模型。
3. 已产生调用的模型版本不可覆盖修改；要调整参数时，必须点“复制为新草稿”，在新版本完成测试后再启用。

## 一、负责人先配置服务器 Key

在项目根目录复制示例文件：

```bash
cp infra/backend.env.example infra/backend.env
```

打开 `infra/backend.env`，只由负责人填写真实 Key。例如：

```dotenv
# 任一 OpenAI 兼容渠道的 Key；变量名可自行命名，但模型中心的 secret_env_name 必须完全一致。
TEXT_OR_VISION_PROVIDER_KEY=这里填写真实的中转站密钥

# 火山方舟的视频 Key。
ARK_API_KEY=这里填写真实的火山方舟密钥
```

保存后重启 API 服务和 Worker。Key 不要发到群里、飞书文档、截图或网页表单中。

## 二、打开 V1 模型中心

启动前后端后，浏览器打开：`http://127.0.0.1:5173/model-profiles`。

页面按“功能”而不是按程序步骤列出模型。每一项都能保存多个版本，旧版本不会被覆盖。草稿、已启用但未调用的版本可直接编辑；一旦产生调用记录，只能复制为新草稿，确保历史项目仍可复现。

## 三、按这个顺序配置

### 1. 分析参考视频

- 功能选择：`分析参考视频`
- 中转站类型：系统自动选择“视觉分析模型”
- 模型名称：从中转站复制 Gemini 3.1 Pro Preview 的实际模型名
- API 地址：中转站文档给出的 `https://.../v1`
- 服务器变量名：例如 `TEXT_OR_VISION_PROVIDER_KEY`

保存为候选即可。这个模型必须支持“图片 + 文字”的 Chat Completions 接口；系统会在 Worker 中从上传视频抽取少量画面，要求它输出：脚本结构、爆款开头、爆款元素、场景分析和创作简报。

### 2. 并行生成原创故事

重复三次选择 `并行生成原创故事`，分别保存：

- Claude Sonnet 4.6
- Claude Opus 4.6
- Gemini 3.1 Pro Preview

它们都使用“文本模型（OpenAI 兼容）”协议。先保存候选；验收通过后，分别点击“启用此版本”。这是唯一允许多个模型同时启用的 V1 槽位，系统会为每个模型分别产出一个故事候选。

### 3. 角色、场景与导演分镜

分别配置：`设计角色文字资产`、`设计场景文字资产`、`AI 导演生成分镜`。

V1 可以先让这三项使用同一个性价比好的文本模型。每个功能仍需单独保存一版配置，因为未来可独立替换、比较成本和回溯结果。

### 4. 图片资产

分别配置：

- `生成角色参考图`
- `生成场景参考图`
- `生成分镜关键帧`

模型名称填写 Banana 2 在中转站显示的实际名称。关键帧页面会多出“参考图字段名”：这是中转站 API 文档中表示“传入参考图”的字段，常见为 `images`，但必须以你所用中转站的文档为准。

关键帧不能使用不支持参考图的图片模型。系统会把锁定后的角色图、场景图传给模型；没有配置该字段时会停止任务，而不是假装使用了锁图。

### 5. 视频片段

- 功能选择：`生成视频片段`
- 系统默认模型名：`doubao-seedance-2-0-mini-260615`
- Adapter：`volcengine_ark_video`
- 服务器变量名：`ARK_API_KEY`
- 选择 9:16 与 3 秒或 5 秒进行第一轮测试

系统会为每个镜头创建独立子任务，使用已锁定关键帧及其角色/场景引用提交火山方舟，保存任务号后轮询至完成，再进入人工视频审核。Worker 重启后只会继续查询已有任务号，不会重新提交。

真实视频必须能从公网读取首帧图片。因此正式生产必须让图片模型结果成为稳定的 HTTPS 地址。建议配置 S3/MinIO + HTTPS CDN：

```dotenv
GENERATED_IMAGE_DELIVERY_MODE=s3
S3_PUBLIC_BASE_URL=https://你的图片公开域名/ai-drama-media
```

详见 `图片结果对象存储说明.md`。

### 6. 合成最终成片

选择 `合成最终成片` 时不需要 AI Key。它使用服务器上的 FFmpeg 下载审核通过的视频片段并输出 MP4。

生产服务器需要安装 `ffmpeg` 和 `ffprobe`。如果最终成片也需要稳定外网地址，建议同时启用 S3 成片交付：

```dotenv
FINAL_VIDEO_DELIVERY_MODE=s3
```

## 四、如何安全切换

- 单模型功能：点击“启用此版本”时，系统会停用该功能此前正在使用的版本；旧配置和历史任务不会删除。
- 故事生成：允许同时启用多个模型。启用真实模型后，请把“本地模拟：故事导演”逐个点“停止使用此版本”，避免它混入真实候选。
- 已经开始的项目：永远继续使用自己冻结的模型/Prompt/Workflow 版本，不受之后切换影响。
- 想改一个已使用的模型：点击“复制为新草稿”，修改模型名或非敏感参数，跑小样本后再启用。不要修改旧版本。
- 想删除一个候选：未启用且未使用的版本可直接删除。已启用模型会先检查是否有进行中的 V1 任务冻结引用；有任务时禁止删除。已有历史调用或质量评估的版本也会保留，确保历史项目可追溯。

## 五、第一次真实验收建议

不要直接跑长剧。创建一个测试项目，上传你有权使用的短参考视频，然后按 V1 固定顺序逐步检查：

1. 视频分析是否出现五类可审核结果；
2. 锁定简报后，故事是否由每个启用模型各出一份；
3. 角色图和场景图是否可查看、可锁定；
4. 导演分镜是否只引用已经锁定的资产；
5. 关键帧是否保持角色/场景一致；
6. Seedance 是否返回可播放片段；
7. 每个片段审核通过后，FFmpeg 是否生成完整成片。

任何一步失败都先看该项目页面中的任务错误，再确认：服务器变量名是否和 `backend.env` 一致、模型名是否从中转站复制、图片是否为 HTTPS、Worker 是否已重启。

## 六、成本和质量怎么比较

每一次调用都会保存模型版本、Prompt 版本、时延、输入/输出引用以及视频任务号。为了让制作负责人不再手工整理 Excel，V1 已提供“质量报表”页面：

1. 在生产台审核每个结果时，可选填写 1 至 10 分；不评分不会阻塞正常生产。
2. 在模型中心填写某个模型的“预计每次生成费用（元）”后，系统会把它作为比较用预估值；这不是供应商的真实账单。
3. 打开 `http://127.0.0.1:5173/model-quality`，点击“生成最新报表”。该操作只读取历史调用和审核，**不会**重新调用模型或扣费。
4. 只在相同用途下比较人工评分、成功率、已审核采用率、预计成本和平均耗时；之后由人回到模型中心决定是否启用候选模型。

详见 `LemonFlow_V1_模型质量报表操作.md`。V1 不会自动选择最低价或最高分模型。
