# LemonFlow V1 完整成片导出说明

“合成成片”不是把页面上看到的任意视频随意拼接，而是严格使用当前导演方案下每个 `ShotPlan` 的 **当前采用且审核通过** 视频版本。

## 合成规则

1. 每个目标镜头必须有 `selected_video_clip_id`。
2. 该片段必须是 `APPROVED`。
3. 系统按分镜号排序，冻结这一组片段 ID 与顺序到新的 `FinalVideo`。
4. FFmpeg 下载冻结片段并重新编码输出 MP4。
5. 以后重做镜头只会产生新片段版本，不会改写已经导出的成片；再次合成才会产生新的成片版本。

历史 `REJECTED` 片段、非当前采用版本和未审核片段绝不会参与“全部审核通过”的判断，也不会进入最终合成。

## 配置真实 MP4 合成

模型中心中为成片合成启用：

| 字段 | 建议值 |
| --- | --- |
| Adapter | `ffmpeg_concat` |
| 模型标识 | `ffmpeg-concat-v1` |
| API Key | 不需要 |
| 单片段下载超时 | 120 秒起 | 
| FFmpeg 超时 | 1800 秒起 |

Worker 必须安装 `ffmpeg` 与 `ffprobe`，并有足够的临时磁盘和网络带宽。真实片段必须有可访问的 HTTPS 视频地址。默认 `FINAL_VIDEO_DELIVERY_MODE=local` 适合单机验收；多机生产应设置 `FINAL_VIDEO_DELIVERY_MODE=s3`，将输出上传至 S3/MinIO 的稳定 HTTPS 地址。

## 用户操作

1. 在生产台确认每个镜头均显示“当前采用 / 审核通过”。
2. 如果某个镜头不满意，驳回并只重做该镜头，再审核新版本。
3. 当工作流进入 `FINAL_EXPORT` 后，点击“合成成片”。
4. 等待状态成功，再下载或预览新成片版本。

## 常见问题

- **不能合成**：至少一个镜头没有当前采用的 APPROVED 视频。回到视频审核逐个处理。
- **无法下载片段**：供应商 URL 已过期、需要登录或不是公开视频地址。先重新生成该镜头并确认对象存储交付。
- **FFmpeg 失败**：检查 Worker 的 FFmpeg、临时磁盘、下载权限和片段可播放性；任务结束后临时文件会清理。
- **成片没有使用刚通过的新版**：查看项目追溯中这次 `FinalVideo` 冻结的片段 ID。已经创建的合成任务使用创建时快照；需要重新合成才能使用之后选择的新版本。
