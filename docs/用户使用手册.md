# LemonFlow V1 用户使用手册

这份手册面向没有程序经验的制作人员。你只需在浏览器操作；模型 Key、数据库和 Worker 由负责人或技术人员维护。

## 开始前确认

1. 使用你有权使用的参考视频。LemonFlow 只可提炼创作结构，不用于复制原视频。
2. 打开首页，创建项目，然后点击进入项目的 **LemonFlow V1 生产台**。
3. 若是第一次使用，先请负责人在“模型中心”启用本地模拟配置，或完成真实模型小样本配置。没有模型配置时，生产台不能生成内容。

## 正式工作流

### 1. 上传、勾选并分析参考视频

可以一次上传多个 MP4/MOV 等真实可播放的视频。上传时系统会校验文件大小、扩展名和 MIME 类型；开始分析时会再验证媒体是否可解码，损坏文件或伪造格式会被拒绝。

上传完成后，它们只会出现在“待分析视频”列表，**不会调用模型，也不会扣费**。请勾选其中一条，再点击“开始分析已勾选视频”。如果上传错了，可在尚未分析前点击“删除”；已作为分析任务输入的视频会被冻结，不能删除，以保证历史可追溯。

分析完成后查看五类结果：

- 视频脚本结构；
- 爆款开头；
- 爆款元素；
- 场景分析；
- 创作简报。

确认它们只是在提炼结构、机制和情绪，而不是复刻原内容。填写审核人和备注后，点击“确认并锁定创作简报”。锁定后本版分析不能编辑；若不满意，请驳回并新建分析版本。

### 2. 生成并选择原创故事

点击“并行生成原创故事方案”。系统会按创建任务时冻结的故事模型顺序生成多份候选。比较故事是否保留结构和情绪机制，同时拥有新的角色、情节与画面表达。

选择一份后点击“选用此故事”。一个项目在同一轮只能有一份当前选中故事；改选需要通过生产台创建新的合法版本，不能直接覆盖历史选择。

### 3. 角色资产与角色图

点击“生成角色资产”。确认角色的年龄、外貌、服装和气质，再生成角色参考图。每个角色可有多个图片版本；从中选择可用版本并点击“锁定”。锁定后，该版本会沉淀到 **资产中心**，以后可在其他项目复用。

如果已有经过验证的角色，不必重新出图：在生产台的角色图片卡片中，从“采用资产中心角色版本”选择一个版本并点击“采用为候选”，再像普通图片一样人工锁定。采用不会跳过审核，也不会自动调用模型或扣费。

只有每个参与分镜的角色都有锁定图，系统才会允许进入场景阶段。

### 4. 场景资产与场景图

生成场景资产，检查地点、环境、风格和氛围。为每个场景生成参考图并锁定一个版本。场景图也不会覆盖旧版本。

已有场景（如医院、办公室、古风院落）可从资产中心采用为候选，仍需在项目内锁定后才能进入导演分镜。

### 5. 导演分镜与关键帧

点击“生成 AI 导演分镜”。分镜会引用已锁定的角色和场景资产。现在每镜会展示动作、情绪、镜头类型、运镜、光线，以及图片、视频、声音提示词；这些内容会和角色/场景资产版本一起冻结。确认画面连续性后，生成每个镜头的关键帧。

逐个选择并锁定关键帧版本。后续视频只能使用锁定的角色图、场景图和关键帧，避免人物和场景漂移。

### 6. 生成和审核视频片段

点击“生成视频片段”。每一个分镜是独立任务，页面会显示各镜头状态和脱敏后的供应商任务号。

- 效果正确：点击“通过”。该版本成为该镜头的当前采用版本。
- 效果不正确：点击“驳回”，然后只重做该镜头。旧片段会保留作历史记录，但不再参与成片。
- 页面刷新或前端停止等待：不代表后台失败。重新打开生产台即可读取现有任务状态；不要反复点击生成。

只有每个镜头都有一个当前采用且已通过审核的视频片段，才会出现“合成成片”。

### 7. 合成和下载成片

点击“合成成片”。系统会冻结本次采用的片段 ID 和顺序，再交给 FFmpeg 合成一版新的成片。之后再重做某个镜头不会改写已经完成的成片；需要再次点击合成才会产生新版本。

任务成功且存储已配置后，页面会显示下载入口。

## 遇到问题怎么办

- **按钮不能点击**：查看生产台顶部的当前阶段和阻塞原因。V1 不允许跳过人工审核。
- **任务失败**：先看该任务的错误信息；不要连续重试收费模型。确认模型配置、Worker、图片 HTTPS 地址和供应商权限后，再人工新建任务。
- **视频一直生成中**：记录页面显示的脱敏任务号，请技术人员查询 Worker 与供应商状态。Worker 重启后会恢复已有任务号的查询，不会重新提交。
- **想查某次结果用了什么模型/Prompt**：打开项目“生产追溯”页，按运行记录定位。

更多配置和故障处理见 [部署与模型配置快速指南](部署与模型配置快速指南.md)。

跨项目资产的建立、版本更新和采用规则见 [资产中心操作](资产中心操作.md)。
