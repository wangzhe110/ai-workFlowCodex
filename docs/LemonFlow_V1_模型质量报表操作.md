# LemonFlow V1 模型质量报表操作

这份说明面向制作负责人。你不需要懂模型参数，也不需要写代码；只要在正常审核时顺手给分，系统就会把效果、速度、采用情况和预估费用整理成可比较的报表。

## 先理解：这不会自动换模型

报表的作用是帮你做决定，不是替你做决定。

- 它不会重新生成故事、图片或视频，所以点击“生成最新报表”不会产生新的模型费用。
- 它不会因为某个模型更便宜或分数更高就自动切换。
- 要切换时，仍然由你在“模型配置”页面点击启用候选版本。

## 一、正常审核时填写评分

打开任一项目生产台。在“人工审核备注”区域可以看到：审核人、质量评分、备注。

1. 填写审核人，例如“制作人小王”。
2. 选择质量评分：1 分代表完全不可用，10 分代表可直接采用。
3. 可选填写原因，例如“角色稳定，但第 2 镜动作僵硬”。
4. 再点击本阶段的确认、锁定、选择、通过或驳回。

评分是可选的。赶时间时可以不填，生产流程照常推进；只是报表会显示“暂无评分”。

“评分”和“采用”不是一回事。例如故事 A 得了 8 分，但因为不适合本次题材而没有被选择；这条记录仍能帮助你评估模型质量。

## 二、填写预计费用（可选）

打开“模型配置”，选择对应的功能和模型版本。新增候选时可以填写“预计每次生成费用（元）”。

- 可以先不填，报表中成本会显示“未填写”。
- 填写的是方便比较的预估值，不是中转站或火山方舟的真实账单。
- 同一模型每次费用差异很大时，建议先留空，或者只把它作为粗略参考。

真实账单对接属于后续增强；不能把预估费用当作财务对账依据。

## 三、生成与查看报表

浏览器打开：`http://127.0.0.1:5173/model-quality`。

1. 可以选择“全部用途”，或只看“原创故事生成”“图片资产生成”等一个用途。
2. 点击“生成最新报表”。
3. 系统读取历史模型调用和审核记录，保存一份新的、不可覆盖的统计快照。
4. 在表格中比较同一个用途下不同模型与 Prompt 版本的行。

如果看到“还没有可比较的数据”，先正常完成至少一次生成；然后回到本页再点击“生成最新报表”。

## 四、每一列是什么意思

| 列 | 怎么看 |
| --- | --- |
| 样本 | 已完成的模型调用数量；样本太少时不要急着下结论。 |
| 成功率 | 该模型任务成功完成的比例，不代表内容质量。 |
| 人工评分 | 你和团队在审核时填写的 1–10 分平均值。 |
| 已审核采用率 | 已经做出审核决定的结果里，被锁定、选择或通过的比例；尚未审核的结果不参与计算。 |
| 预计每次成本 | 模型中心中手工填写的单次预估费用；没有填写就显示“未填写”。 |
| 平均耗时 | 从平台发出调用到收到完成结果的平均时间。 |
| Prompt | 该次生产实际使用的 Prompt 模板与版本，便于区分“模型变了”还是“提示词变了”。 |

建议一次只比较同一个用途、相近的内容样本。例如不要拿“故事生成”和“视频生成”的耗时或成本互相比较。

## 五、如何安全地决定切换

1. 用两个候选模型各跑一小批相同类型的测试项目。
2. 审核时坚持给分，并记录典型问题。
3. 到质量报表查看评分、成功率、采用率、预计成本和耗时。
4. 选定一个候选后，返回“模型配置”，手动点击“启用此版本”。
5. 再用一个真实小项目验收后，才在正式生产中持续使用。

旧模型、历史调用、审核评分、Prompt 版本和报表快照都不会被覆盖，因此以后可以随时追溯当初为何换模型。
