# 后端测试模块

测试重点是用户可见的闭环与关键状态规则，而不是 FastAPI/SQLAlchemy 本身：

- 创建项目；
- 上传参考视频；
- 创建视频分析工作流；
- 验证后台执行后的成功状态和合规结果字段。
- 维护爆点元素、爆款开头等抽象创作资产，并验证软停用保留审计记录。
- 成功分析后生成原创选题候选，并验证确认选题必须由人工接口触发。
- 已确认选题生成故事包，并验证只有人工确认后的故事包可供后续分镜使用。
- 已确认故事包生成镜头数量可配置的分镜细纲，并验证其人工确认状态。
- 确认分镜后生成带版本的单镜图片，并验证视频片段必须等待每镜成功图片。
- 按可配置镜头数分组生成视频片段，验证单组重做只新增该组版本。
- 验证每个步骤的默认模型配置会初始化，候选中转站配置不能在适配器未接通时被误启用，且数据库拒绝保存 API Key。
- 验证 OpenAI 兼容文本适配器会正确补齐接口地址、读取环境变量并解析 JSON，而测试不会向真实中转站发出请求。
- 验证图片结果可转存至 S3/MinIO 并返回稳定 HTTPS 地址；HTTP 与 S3 客户端均使用假实现，不访问真实外部服务。
- 验证进程存活检查和数据库就绪检查分离，避免“接口还能响应”被误判为“生产依赖可用”。
- 验证超过 Worker 安全阈值仍在执行的任务会转为失败并可人工重试，避免页面永久转圈或自动重复扣费。
- 验证模型配置预检不调用生成能力、不会暴露密钥，并能明确指出服务器未注入的密钥变量。
- 验证模型小样本验收记录可按配置版本保存成本、耗时、质量和成功率，且拒绝错误统计。
- 验证同一步骤的模型实测对比会带回配置版本标识，不将不同测试场景伪造为一个平均分。
- 验证 LemonFlow V1 数据表已注册、同一项目不能同时选择两份故事方案，且故事模型槽位可声明多模型并行策略。
- 验证 V1 审核的 1 至 10 分质量评分会进入模型质量快照，刷新报表只读取已有数据且不会自动修改模型槽位。
- 验证 V1 完整闭环可通过安全追溯接口返回冻结的 Workflow、模型和 Prompt 版本，且不返回原始模型输入或输出。

`conftest.py` 会在导入应用前切换到独立 SQLite 文件和独立本地资产目录，防止测试触碰开发或生产数据。生产接入 Redis Worker 后，需补充任务投递、幂等、超时与死信队列的集成测试。
