# 豆包 Seedance 视频操作说明

本文对应 LemonFlow V1 的视频片段能力：`doubao-seedance-2-0-mini-260615`。业务流程只称它为“视频生成槽位”；模型协议由 `volcengine_ark_video` Adapter 封装，页面不需要填写提交路径或轮询 JSON。

## 一次性配置

在部署环境或不提交的 `infra/backend.env` 中配置：

```dotenv
ARK_API_KEY=
```

重启 API 和 Worker 后，打开“模型中心”，为“视频片段”新建候选：

- Adapter：`volcengine_ark_video`
- 模型：`doubao-seedance-2-0-mini-260615`
- Key 变量名：`ARK_API_KEY`
- 第一次样本建议：9:16、3 或 5 秒

运行基础预检后，只为 **一个 ShotPlan（一个分镜）** 创建视频任务。验收通过后再启用到正式项目。

## LemonFlow 在后台做什么

1. 在任务创建时冻结该镜头使用的角色图、场景图、关键帧、动作描述、模型和 Prompt。
2. 每个镜头创建一个独立视频子任务与一个片段版本。
3. 首次提交后立即保存供应商任务号；页面只显示脱敏任务号。
4. Worker 重启或轮询中断时，使用已有任务号继续查询，绝不重新提交同一供应商任务。
5. 生成成功后进入人工审核。审核通过的版本成为该镜头的当前采用版本。

真实视频生成要求首帧/参考图片能被供应商访问，必须是稳定的公网 HTTPS 地址。生产建议将生成图片转存至 S3/MinIO 并配 HTTPS CDN，见 [图片结果对象存储说明](图片结果对象存储说明.md)。

## 重做一个镜头

1. 在生产台找到不满意的镜头，点击“驳回”。
2. 只为该镜头重新生成新版本；不要重新生成全部镜头。
3. 审核新版本并点击“通过”。
4. 新版本变为当前采用版本；旧 REJECTED 版本留在历史记录中，但不会阻挡成片，也不会被成片使用。

## 常见问题

| 提示/现象 | 处理方式 |
| --- | --- |
| `ARK_API_KEY` 未设置 | 检查服务器环境变量，重启 API 与 Worker。 |
| 首帧不是 HTTPS 地址 | 使用真实图片模型并配置对象存储/CDN；本地文件和 `mock://` 地址不能发给真实供应商。 |
| 生成中页面超时 | 页面停止等待不等于任务失败。刷新后读取原任务状态，依据供应商任务号和 Worker 日志排查。 |
| 模型未开通 | 到火山方舟控制台检查模型权限和余额；不要连续重试。 |
| 视频失败 | 查看镜头子任务错误，确认后人工新建该镜头新版本。 |

协议参考：[火山方舟异步内容生成文档](https://docs.volcengine.com/docs/82379/1399008?lang=zh)。账户实际可用性、模型名、计费和限制以火山方舟当前控制台和文档为准。
