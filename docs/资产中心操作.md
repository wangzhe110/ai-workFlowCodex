# 资产中心操作

资产中心是 LemonFlow Phase 4 的跨项目角色、场景复用区。它不是素材回收站：这里保存的是已经整理好的角色或场景设定，以及其不可覆盖版本。

## 最重要的规则

1. 不要编辑旧版本。想改外貌、服装、天气、时段或参考图时，点击“新增版本”。
2. 一个版本被任何项目采用后，仍会永久保留。这样旧项目的分镜、关键帧和视频才能复现。
3. 把资产放进项目不是最终确认。它会先成为“待锁图候选”，制作人还要在生产台点击锁定。
4. 资产中心不保存模型 Key，也不会因为新建资产自动出图或扣费。

## 新建角色资产

1. 顶部菜单打开 **资产中心**，选择“角色资产”。
2. 填写角色名称、外貌、服装、性格和视觉风格。
3. 如已有参考图，可粘贴正面、侧面、全身、表情图的 HTTPS 地址；没有也可以先保存文字设定。
4. 点击“创建角色资产 v1”。

以后想增加雨夜服装、不同年龄段或更稳定的表情图，打开该角色并点击“新增版本”。系统会以旧版内容作为起点，保存后变为 v2，v1 不会被改动。

## 新建场景资产

1. 选择“场景资产”。
2. 填写地点、环境、视觉风格、天气、时段和氛围。
3. 可添加全景、细节等参考图地址。
4. 点击“创建场景资产 v1”。

例如“城市医院走廊·夜晚小雨”和“城市医院走廊·黎明”应该是不同版本，而不是直接修改同一条记录。

## 在项目中采用一个资产

1. 项目进入“角色资产”或“场景资产”阶段后，先生成项目的文字设计与候选图。
2. 在相应图片卡片的“采用资产中心…版本”下拉框中选择已验收版本，点击“采用为候选”。
3. 系统会新增一张项目候选图，不会覆盖原来的 AI 出图，也不会调用图片模型。
4. 检查候选图后点击“锁定此…版本”。只有锁定后的版本才会进入导演分镜。

导演方案、关键帧和 Seedance 视频片段会同时记录项目锁图 ID 与资产中心版本 ID。资产中心随后增加 v2，不会改变已经创建的任务或成片。
