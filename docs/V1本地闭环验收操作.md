# LemonFlow V1 本地闭环验收操作

本说明用于 **不配置任何真实模型 Key、不产生费用** 的本地 Mock 验收。模拟结果只用于检查状态机、审核、版本、幂等和页面交互，不能发布为真实内容。

## 操作步骤

1. 按根目录 README 启动前端和后端，打开项目首页。
2. 创建项目，上传一个你有权使用、可正常播放的短视频。
3. 在生产台点击“开始视频分析”，检查五类分析结果后锁定创作简报。
4. 点击“并行生成原创故事方案”，选择一份故事。
5. 生成角色文字资产和角色图，为每个角色锁定一个版本。
6. 生成场景文字资产和场景图，为每个场景锁定一个版本。
7. 生成 AI 导演分镜，再生成并锁定每个分镜关键帧。
8. 生成视频片段，逐镜审核通过。
9. 进入 `FINAL_EXPORT` 后合成成片。显示完成即表示主流程状态机已走通；Mock 成片可能是 `mock://` 地址，不会假装可下载 MP4。

## 专项验收：视频驳回后重做

1. 先为至少三个镜头生成片段。
2. 驳回第二个镜头，再只生成该镜头的新版本。
3. 审核通过新版本，并确认其他两个镜头保持通过。
4. 验证项目进入 `FINAL_EXPORT`，合成成片。
5. 在追溯信息中确认成片只冻结三个当前采用片段，不包含第二镜头旧的 REJECTED 版本。

## 你应当看到的保护

- 重复点击同一阶段的生成按钮，只会得到已有的 `PENDING` 或 `RUNNING` 任务。
- 任务创建后切换模型或 Prompt，不影响该任务；新任务才使用新配置。
- 刷新页面不会重新提交视频供应商任务；已有镜头会显示原有状态和脱敏任务号。
- 锁定/审核后的版本不会被覆盖，所有重做都创建新版本。

如果页面出现 `mock://`，说明你正在正确使用本地模拟。要验证真实模型，请改用 [真实模型配置操作](LemonFlow_V1_真实模型配置操作.md) 的授权小样本流程。
