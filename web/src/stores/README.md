# 状态模块

Pinia Store 负责跨组件项目数据、加载状态、错误状态和轮询生命周期。

- `project.ts`：V1 生产台的项目、审核、生成运行、资产版本、镜头视频状态和联动刷新。
- `model-profiles.ts`：模型槽位、候选版本、预检、启用、质量和 Prompt 相关页面状态。
- `creative-library.ts`：可选创作资产库。

轮询由 Store 集中管理。页面离开时停止本页定时请求，但不得把后台 `PENDING`/`RUNNING` 任务标为失败；重新进入时应读取后端已有状态。重复提交由后端幂等约束保护，Store 仍应在按钮等待期间避免重复发起请求。
