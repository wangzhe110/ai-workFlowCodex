# 前端接口模块

所有浏览器 HTTP 请求集中在这里；页面和组件不得直接调用 `fetch`。

- `http.ts`：统一 API 地址、JSON、错误转换和请求基础能力。
- `projects.ts`：项目、授权参考视频上传/删除和历史兼容接口；V1 上传只保存候选素材。
- `production.ts`：V1 生产状态、审核/锁定、显式选中参考视频后的生成运行、镜头视频状态、模型/Prompt/质量/追溯接口；不包含具体供应商协议或 Key。
- `model-profiles.ts`：非敏感模型配置、候选、预检和人工启用接口。
- `creative-library.ts`：可选的抽象创作资产库。
- `asset-library.ts`：角色/场景资产中心和追加版本接口；不发送或保存真实模型 Key。
- `production.ts`：另含当前结构化导演方案读取，以及把资产中心版本作为项目待锁图候选采用的接口。

前端不应把轮询超时误写成任务失败：它只停止本页等待；刷新或重新进入项目后继续从后端读取既有运行和镜头状态。
