# 豆包 Seedance 视频操作说明

这份说明对应当前参考工作流使用的视频模型：`doubao-seedance-2-0-mini-260615`。

你不需要配置接口地址、提交路径、任务查询或 JSON。系统已经把火山方舟的视频协议封装好了；你只要完成一次 Key 配置，然后在页面选择竖屏和时长。

## 第一次只做一次：放入方舟 Key

由负责人打开 `infra/backend.env`，增加：

```dotenv
ARK_API_KEY=你的火山方舟 API Key
```

保存后重启后台：

```bash
docker compose --env-file infra/compose.env up -d --force-recreate api worker
```

真实 Key 不要填到网页、模型名称、聊天记录或截图中。

## 在网页怎么启用视频模型

1. 打开“模型配置中心”。
2. 在“这台模型要做什么”选择“视频片段”。
3. 页面会自动填入 `doubao-seedance-2-0-mini-260615`，不要修改模型名称。
4. 选择“竖屏短剧（9:16）”和“5 秒”。第一次建议保持这两个默认值。
5. 点击保存，然后在右侧点击“基础预检”。
6. 预检通过后，先新建一个测试项目，只生成 **1 组镜头**。
7. 确认视频正常、画面合格且费用符合预期后，再点击“启用此版本”。

## 系统在后台替你做了什么

系统会自动使用火山方舟的异步视频任务流程：

1. 将视频提示词和第一张分镜图片提交给 Seedance；
2. 保存返回的任务编号；
3. 自动查询任务状态；
4. 成功后保存视频地址，并作为一个可单独重做的视频片段版本。

第一张分镜图片必须是第三方可以访问的 `https://` 地址。模拟图片或电脑本地图片不能直接传给真实视频模型；否则系统会在发起付费任务前阻止操作。

## 常见问题

| 提示 | 处理方式 |
| --- | --- |
| `ARK_API_KEY` 未设置 | 请负责人检查 `infra/backend.env`，保存后重启 API 和 Worker。 |
| 首帧图片不是 HTTPS 地址 | 先使用真实图片模型生成图片，或把图片保存到对象存储。 |
| 模型未开通/权限不足 | 到火山方舟控制台确认该模型已开通，且当前 Key 有权限。 |
| 视频生成失败或很慢 | 不要连续重试；先查看该片段的错误提示和 Worker 日志，避免重复扣费。 |
| 仍显示 `mock://` | 视频模型还没启用，或当前项目运行时仍冻结了旧的模拟配置。重新创建一轮视频片段即可使用新模型。 |

## 给技术人员的协议说明

这是一个系统内置适配器：`volcengine_ark_video`。它固定使用火山方舟 API 基地址
`https://ark.cn-beijing.volces.com/api/v3`，创建任务路径为
`/contents/generations/tasks`，并查询 `/contents/generations/tasks/{task_id}`。
首帧采用 `image_url` 且角色为 `first_frame`；成功时读取 `content.video_url`。

参考：[火山方舟快速入门与异步内容生成示例](https://docs.volcengine.com/docs/82379/1399008?lang=zh)。模型能否使用仍以当前火山方舟账户的开通状态为准。
