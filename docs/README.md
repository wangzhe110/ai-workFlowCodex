# LemonFlow V1 文档入口

本目录只保留与当前 LemonFlow V1 代码和正式生产链路一致的文档。旧的“原创选题 → 故事包 → 分组视频”“语音转写”等历史流程不再作为操作入口。

## 制作人员先看

- [用户使用手册](用户使用手册.md)：从上传授权参考视频到下载成片的日常操作。
- [V1 本地闭环验收操作](V1本地闭环验收操作.md)：不配置 API Key、不产生费用的流程验收。
- [模型配置小白操作卡](模型配置小白操作卡.md)：模型中心每个槽位应该配置什么。
- [真实模型配置操作](LemonFlow_V1_真实模型配置操作.md)：授权小样本的真实模型验收顺序。
- [豆包 Seedance 视频操作说明](豆包Seedance视频操作说明.md)：Seedance 视频片段的配置、重做与恢复查询。
- [完整成片导出说明](完整成片导出说明.md)：仅使用当前采用且审核通过片段的合成规则。
- [资产中心操作](资产中心操作.md)：创建角色/场景资产版本，并在项目中作为待锁图候选采用。

## 生产管理与追溯

- [模型质量报表操作](LemonFlow_V1_模型质量报表操作.md)：比较人工评分、采用率、预计成本和耗时；只供人工决策。
- [Prompt 模板操作](LemonFlow_V1_Prompt模板操作.md)：创建、验收、启用和归档 Prompt 版本。
- [生产追溯操作](LemonFlow_V1_生产追溯操作.md)：定位一个项目实际冻结的 Workflow、模型、Prompt 和供应商任务号。
- [LemonFlow V1 架构设计](LemonFlow_V1_Architecture.md)：数据关系、状态机、能力槽位和兼容边界的架构基线。

## 部署与运维

- [部署与模型配置快速指南](部署与模型配置快速指南.md)：Docker、本地/生产启动、Key 注入、模型预检和小样本验收。
- [模型配置预检说明](模型配置预检说明.md)：不产生内容的上线前检查边界。
- [Redis/RQ Worker 部署说明](Redis_RQ_Worker部署说明.md)：独立后台任务、镜头子任务和故障处理。
- [图片结果对象存储说明](图片结果对象存储说明.md)：稳定 HTTPS 图片地址和 S3/MinIO 交付。
- [运维备份恢复说明](运维备份恢复说明.md)：数据库与媒体对象的备份、恢复和演练。

启动 API 后可访问 `http://127.0.0.1:8000/docs` 查看实际 OpenAPI 契约。页面、接口和状态以代码为准；任何真实 Key、账单截图或用户媒体都不应写入文档。
