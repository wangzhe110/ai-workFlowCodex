# 模型配置预检说明

每一项模型配置都可以在“模型配置中心”点击“基础预检（不生成内容）”。预检用于在
花费模型额度前发现部署问题，不会把 API Key 返回到浏览器或写进数据库。

## 预检会做什么

- 检查该工作流步骤的供应商适配器是否已写入当前系统；未接入的供应商只能保存为候选，不能启用。
- 检查 API 地址、路径、字段映射、超时、抽帧/音频/FFmpeg 预算等非敏感配置。
- 检查 `secret_env_name` 所指向的服务器环境变量是否已经注入；只显示变量名，不显示值。
- OpenAI 兼容文本、图片、视觉、语音模型：在密钥存在时调用只读 `/models`，确认 API 服务能连通中转站且模型目录可查询。该请求不生成内容。
- 完整成片步骤：检查当前 API/Worker 镜像能否执行 FFmpeg。

## 为什么异步图生视频不自动做联网测试

不同中转站没有统一的“零费用健康接口”。直接提交测试视频即使客户端超时，也可能在
供应商侧已经创建并收费。因此预检只检查适配器、字段映射和密钥；通过后，请创建一
个测试项目，用 **1 组镜头** 做真实验收，确认提交路径、任务号字段、轮询状态、视频
地址和成本都符合预期，再把该版本启用到正式生产步骤。

## 推荐操作顺序

1. 在 `infra/backend.env` 或部署平台 Secret 写入真实密钥变量，例如 `YUNWU_API_KEY`，并重启 API 和 Worker。
2. 在模型配置中心新增候选版本，先不要勾选“立即启用”。
3. 点击基础预检，逐项处理“未通过”；“提示”表示该中转站不支持标准目录接口，仍需小样本验收。
4. 对文本、图片、视觉、转写执行最小测试项目；对异步视频只生成 1 组镜头。
5. 记录成本、耗时、成功率和内容质量，再启用通过验收的版本。历史任务仍会使用创建时冻结的旧配置，不受切换影响。
