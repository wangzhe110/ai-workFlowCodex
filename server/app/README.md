# 应用代码模块

`app` 是后端 Python 包。依赖方向为 `api → services → models/core`：路由不直接修改数据库状态，实体和基础设施不反向依赖 HTTP。

## V1 主链路

`参考分析 → 分析审核 → 多模型故事 → 故事选择 → 角色资产 → 场景资产 → 导演分镜 → 关键帧 → 视频生成 → 视频审核 → 成片导出`。

人工决定必须走 `v1_production_service.py` 状态机；Worker 只能生成候选或写入任务终态，不能替人锁定、选择或通过审核。

## 重要约束

- 模型 Key 只从运行环境读取，不进入实体、接口、日志快照或前端。
- 模型输出先由 Adapter 标准化，再写入平台契约；业务代码不解析供应商私有返回。
- 参考视频分析通过 FFmpeg 抽帧并输出五类抽象结果；V1 主流程不依赖音频转写。
- `/health` 表示进程存活；`/ready` 才检查数据库，并在 RQ 模式检查 Redis。
- 已锁定的分析、资产、视频和成片不可覆盖；新结果必须是新版本。
