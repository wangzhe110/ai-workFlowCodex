# 模型配置小白操作卡

你只需要记住一句话：**模型配置不是把 Key 填到网页里，而是先把 Key 放到服务器，再在网页选择“这台模型做什么”。**

本页不要求你理解 API、JSON、接口路径或代码。看见这些词时，先不要改；系统已经为云雾文本/图片模型和豆包视频模型准备了常用配置。

## 先确认一件事：平台已经启动了吗？

浏览器打开下面地址：

```text
http://127.0.0.1:8000/ready
```

看到 `ok` 才表示后台、数据库和任务执行器都已准备好。然后再打开平台：

```text
http://127.0.0.1:5173
```

## 第一次：请负责人放入 API Key

这一步不在网页操作。负责人需要打开项目中的 `infra/backend.env` 文件，填写：

```dotenv
YUNWU_API_KEY=你的云雾密钥
ARK_API_KEY=你的火山方舟密钥
```

保存后重启后台。真实 Key 是“账户密码”，不能复制到模型配置页面、聊天记录、截图或表格里。

你在网页里看到的 `YUNWU_API_KEY` 或 `ARK_API_KEY` 都只是“变量名”，不是要填写真实 Key 的输入框。

## 网页里只做 5 步

进入左侧的“模型配置中心”。每次只配置一种用途。

1. 在“这台模型要做什么”选择用途，例如“故事创作”。
2. 在中转站后台找到模型名称，复制到“模型名称”。
3. 点击“保存”。第一次不要勾选“保存后立即启用”。
4. 在右侧找到刚保存的版本，点击“第一步：基础预检（不生成、不扣费）”。
5. 预检通过后，开一个小测试项目试一次；满意后点击“最后一步：启用此版本”。

启用后，之后新建的任务会使用这台模型。已完成的历史项目不会因为你换模型而被改掉。

## 每个功能该选什么模型？

| 你在页面选择的用途 | 这台模型负责什么 | 你需要从中转站确认什么 |
| --- | --- | --- |
| 原创选题 | 根据创作方向生成题材和开头钩子 | 它是文本模型，支持中文输出 |
| 故事创作 | 生成大纲、人物和场景 | 它是文本模型，支持中文输出 |
| 分镜细纲 | 把故事拆成镜头和提示词 | 它是文本模型，支持中文输出 |
| 分镜图片 | 为每个镜头生成图片 | 它是图片模型，支持竖屏尺寸 |
| 参考视频的画面与爆点规律 | 分析画面中的开头机制、冲突和节奏 | 它能“看图片”，即视觉模型 |
| 参考视频里的语音 | 分析开头声音的节奏信息 | 它是语音转写模型 |
| 视频片段 | 由图片和提示词生成短视频 | 固定使用火山方舟的 `doubao-seedance-2-0-mini-260615`；页面自动处理接口细节 |
| 合成完整 MP4 | 把视频片段合并成完整视频 | 不需要购买 AI 模型，系统使用 FFmpeg 合成 |

前三项（原创选题、故事创作、分镜细纲）通常可以使用同一台文本模型，但**仍要分别配置三次**，因为将来你可以只替换其中一个步骤，而不影响其他步骤。

## 推荐的第一次接入顺序

不要一次开通所有模型。按下面顺序最稳：

1. 先配置“故事创作”文本模型，生成一次故事，确认文字质量。
2. 再配置“原创选题”和“分镜细纲”，确认整条文字创作流程。
3. 配置“分镜图片”，先生成 1–2 张竖屏图片。
4. 配置“参考视频的画面与爆点规律”，用一条已获授权的短视频测试。
5. 如确实需要声音信息，再配置“参考视频里的语音”。
6. 最后才配置“视频片段”，并且第一次**只生成 1 组镜头**。
7. 视频片段全部成功后，启用“合成完整 MP4”。

每完成一步都做小样本测试。不要因为模型价格低就直接大量生成；先看质量、成功率、耗时和实际单条成本。

## 哪些内容不要碰？

在模型配置页的“高级设置”中有 API 地址、请求路径、JSON、响应映射等内容。第一次配置时：

- 文本、图片、视觉、语音模型：保持默认即可；
- 视频模型：选择竖屏/横屏与时长即可。系统已内置火山方舟的豆包视频协议；
- 完整 MP4 合成：保持默认即可，不需要 Key；
- 不要在任何网页输入框粘贴真实 API Key。

视频模型最特殊：当前参考流程使用的 `doubao-seedance-2-0-mini-260615` 来自火山方舟，
不是云雾。系统已固定接口格式；你只要确认负责人已配置 `ARK_API_KEY`，并在第一次只生成
1 组镜头测试。填错或连续重试都可能造成重复扣费。

## 常见提示，应该怎么办？

| 看到的提示 | 你该做什么 |
| --- | --- |
| 密钥未配置 | 告诉负责人检查 `infra/backend.env` 是否填写了对应 Key，并重启后台 |
| 基础预检不通过 | 截图预检的中文提示；先检查模型名称、账户权限、余额和网络 |
| 适配器尚未接通 | 当前系统不支持你填写的模型类型；不要启用，联系技术人员 |
| 图片生成成功但视频不能生成 | 图片必须是中转站可访问的 HTTPS 地址；本机模拟图片不能直接用于真实视频模型 |
| 视频任务一直等待 | 不要连续点击重试；先检查视频中转站的任务状态和 Worker 日志，避免重复扣费 |
| 成片显示 `mock://` | 仍在模拟模式；需要启用真实视频模型和“完整 MP4 合成” |

## 最简单的判断标准

刚开始只需要问自己三个问题：

1. 我选的是不是正确用途？
2. 模型名称是不是从中转站后台复制来的？
3. 我有没有先预检和小样本测试？

三个答案都是“是”，再点击启用。其余技术配置可以等需要更换中转站或视频模型时再处理。
