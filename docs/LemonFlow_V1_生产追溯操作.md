# LemonFlow V1 生产追溯操作

当你发现故事、图片或视频“不对”时，不要只说“效果不好”。先打开该项目的生产追溯记录，确定问题到底来自模型、Prompt、工作流还是供应商任务。

## 打开记录

进入项目生产台，在右侧“当前等待什么？”区域点击“查看本项目的模型与版本记录”。

也可以直接打开：`http://127.0.0.1:5173/projects/项目ID/trace`。

## 先看哪几列

| 你想确认什么 | 看哪一列 |
| --- | --- |
| 这一步做了什么 | 用途 / 状态 |
| 当时走的是哪版正式流程 | 工作流版本 |
| 当时用的是哪个模型 | 模型版本 |
| 是否因为改 Prompt 造成变化 | Prompt 版本 |
| 是否太慢或成本预估过高 | 成本 / 耗时 |
| 视频供应商任务需要技术人员查询 | 供应商任务号 |

## 反馈问题时这样记录

例如发现“第 3 个镜头人物变脸”，请记录：

1. 项目名称和镜头编号；
2. 生产追溯中对应行的模型名称、模型版本和 Prompt 版本；
3. 供应商任务号（如果有）；
4. 你看到的问题和预期结果。

这样技术人员就能精确复现并判断是图片模型、视频模型、Prompt 还是素材引用出了问题。

## 保护规则

这个页面故意不显示原视频、Prompt 正文、模型输入和模型原始输出，避免素材和内部指令被复制到普通页面。需要进一步排查时，由有权限的技术人员从后端审计记录中按项目范围查看。
