# 云雾模型接入说明（文本与同步图片）

本文覆盖云雾的 OpenAI 兼容**文本**接口，以及已接入的同步图片生成接口。文本适用于本项目的“原创选题”“故事包”“分镜细纲”三个步骤；同步图片适用于“分镜图片”。图生视频使用独立的异步适配器，配置方式见 `云雾异步图生视频接入说明.md`；视频理解仍必须独立接入，不能直接套用本说明。

## 1. 准备密钥

在工程根目录创建未提交的 `.env` 文件，填写：

```dotenv
YUNWU_API_KEY=你的真实密钥
```

密钥绝不能填写到模型配置页面、前端变量、数据库或 Markdown 文档。修改 `.env` 后需要重启后端，才能让运行进程读取新环境变量。

## 2. 新增模型配置

打开前端“模型配置中心”，分别为以下步骤新增配置：

- `generate_original_topics`：原创选题；
- `generate_story_package`：故事包；
- `generate_storyboard`：分镜细纲。

建议填写：

| 字段 | 值 |
| --- | --- |
| 供应商标识 | `openai_compatible` |
| 模型标识 | 从云雾账户后台当前可用模型列表中选择的真实模型名 |
| API 地址 | `https://yunwu.ai/v1` |
| 密钥环境变量名 | `YUNWU_API_KEY` |
| 超时秒数 | 90–180（按模型速度调整） |

配置保存后，勾选“创建后立即启用”，或在候选配置列表中点击“启用此版本”。每一次生成都会冻结当时的模型配置；后续切换模型不会改变既有结果。

## 3. 验证方式

先在一个测试项目中启动“生成故事包”。成功时任务时间线会变为“已完成”；失败时会保存可读错误信息，常见原因是：

- 后端未重启，尚未读取 `YUNWU_API_KEY`；
- 模型名不在该账户可用范围内；
- API 地址或余额/权限配置不正确；
- 模型没有按约定返回 JSON。

前三项应在云雾后台或部署环境排查。最后一项可更换更稳定的文本模型，或针对该模型调整提示词与 JSON 输出能力。

## 图片步骤配置

为 `generate_storyboard_images` 新增配置时，填写：

| 字段 | 值 |
| --- | --- |
| 供应商标识 | `openai_compatible_image` |
| 模型标识 | 云雾后台当前支持的图片模型名 |
| API 地址 | `https://yunwu.ai/v1` |
| 密钥环境变量名 | `YUNWU_API_KEY` |
| 图片尺寸 | 由选定模型支持的尺寸，例如 `1728x2304` |

适配器会调用 `/v1/images/generations`，并保存响应中的图片 URL（也兼容 Base64 返回）。如果某个模型返回的是异步任务号而非图片 URL，请不要启用此配置；需要接入该模型专用的提交、轮询/回调适配器后再使用。

## 4. 安全与生产约束

- 前端不会请求云雾，也不会获得密钥；所有请求由后端 Worker 发出。
- 数据库只保存 `secret_env_name=YUNWU_API_KEY` 这一引用，不保存真实密钥。
- 生产环境应用密钥管理器或部署平台 Secret 注入；不要依赖开发机 `.env`。
- 上线前要为每个候选模型单独做成本、延迟、JSON 合规率和内容质量测试，再启用到生产步骤。
