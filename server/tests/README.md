# 后端测试模块

测试使用隔离 SQLite、临时媒体目录、假 HTTP/S3 客户端和本地 Mock Adapter；不会读取真实 Key 或发出付费模型调用。

重点覆盖：

- V1 从上传、分析锁定、故事选择、角色/场景/关键帧锁定、视频审核到成片的 Mock 闭环；
- 锁定版本不可覆盖、角色/场景/关键帧/视频资产引用可追溯；
- 一个镜头的旧 REJECTED 视频不会阻挡新版 APPROVED 片段进入 `FINAL_EXPORT`，成片只冻结当前采用版本；
- 任务创建时冻结源视频、Workflow、模型列表顺序、Prompt 与上游资产，之后切换中心配置不影响已创建任务；
- 相同 `run_key` 的重复/并发请求返回同一未完成任务，模型调用和视频片段均有幂等键；
- 镜头视频子任务保存/恢复 `provider_task_id`，不会因 Worker 中断重提供应商任务；
- 真实可解码 MP4 的 FFprobe、抽帧、拼接、伪造 MIME/扩展名拒绝、文件上限和临时文件清理；
- Alembic 迁移、模型预检、对象存储交付、健康检查和质量/追溯查询。
- Commerce 领域基础：共享产品冻结版本、多个选题的独立 StoryRun、同选题重跑、
  章节/片段/子镜头/对白、结构化植入、RenderBatch 与既有 WorkflowRun 关联，以及
  `0010` 的升级、回退至 `0009`、再次升级验证。

运行：

```bash
pytest -q
```

真实渠道、真实费用、供应商计费字段和真实生成质量不在自动化测试范围内，必须通过授权小样本人工验收。
