# 路由文件模块

每个路由文件按业务资源拆分。页面与路由的对应关系：

- 项目列表、新建项目、项目详情页面使用 `projects.py`。
- 项目详情中的工作流时间线、任务中心页面使用 `workflows.py`。
- 爆点元素库、爆款开头库管理页面使用 `creative_library.py`。
- 项目选题页使用 `topics.py`，只允许人工确认选题进入后续故事步骤。
- 故事工作台使用 `stories.py`，只有确认故事包能进入分镜阶段。
- 分镜、图片、视频片段和完整成片分别使用 `storyboards.py`、`images.py`、`videos.py`；视频接口会校验确认分镜和每镜成功图片，完整成片接口会冻结片段版本并仅提供项目范围内的下载地址。
- `model_profiles.py`：模型配置中心；只允许保存非敏感参数和环境变量名称，切换已接通的配置版本。

路由不得保存密钥、不得调用具体中转平台、不得访问本地文件路径；这些职责分别属于配置、模型适配和资产服务。
