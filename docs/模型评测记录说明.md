# 模型评测记录说明

“模型配置中心”中的每一个版本都有“记录 / 查看模型实测”。它用于把你试不同中转站、
不同模型、不同参数后的结论沉淀到平台里，之后切换模型时可以回看数据，而不是凭印象。

## 每次该记录什么

完成一轮小样本后，填写：

- **测试场景**：必须写清楚任务类型和规模，例如“9:16、5 镜图生视频小样”或“10 条都市情感选题”。
- **总样本数 / 成功样本数**：成功指产物实际可用，不只是接口返回 200。
- **总成本（元）**：填写该轮从中转站实际扣费的总额。
- **平均耗时（秒）**：从提交到得到可用产物的平均时间；异步视频应包含轮询等待。
- **人工质量评分**：建议统一 0–100 标准，例如人物一致性、指令遵循、镜头连贯性、中文表现和可用率综合评分。
- **备注**：写清楚常见失败、限制条件和推荐用途，例如“适合静态人物图，不适合大动作”。

平台自动计算成功率、单样本成本和单个成功样本成本。

配置中心顶部的“模型实测对比”会把同一工作流步骤下各个模型版本的记录并列显示。
只有测试场景相同的数据才能直接比较；平台刻意不把不同场景混合成一个虚假的平均分。

## 推荐的比较方法

1. 同一工作流步骤、同一测试场景下，至少比较 2 个候选模型。
2. 第一轮用 5–10 个样本排除明显不稳定或不可用的模型。
3. 入围模型用 30 个以上样本复测；不要只看一次刚好成功的结果。
4. 优先看“单个成功样本成本”和成功率，再结合质量分和平均耗时选择。最低单价不一定是最低生产成本。
5. 选择后在配置中心启用对应版本。旧任务使用创建时冻结的配置，新任务才使用新版本，因此可安全回退。

## 数据边界

评测记录只保存汇总数字和人工备注，不保存原参考视频、提示词、模型原始回复、API Key
或供应商原始日志。若备注中涉及客户项目，也不要填写个人信息、未公开素材内容或密钥。
