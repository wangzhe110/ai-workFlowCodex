# 接口契约模块

这里定义 API 的输入输出对象，而不是直接返回 SQLAlchemy 实体。

- `contracts.py`：项目创建、资产、任务、步骤和分析结果的对外字段。

其中还包括创作资产库的增查契约，以及选题候选卡片的稳定字段。选题评分只是辅助排序，最终 `SELECTED` 状态必须由用户确认接口写入。

故事包契约将大纲、角色卡、场景卡作为一个版本化快照输出；只有 `CONFIRMED` 版本可传给后续分镜工作流。

视频片段契约把“每组镜头数”作为请求参数，并返回片段组范围、图片版本、提示词、视频地址和版本号；具体中转站的原始字段不会暴露给前端。

`FinalVideoResponse` 返回完整成片冻结的片段 ID、版本和状态。底层 `storage_key` 永不暴露；只有真实文件已就绪时才会提供受项目范围保护的 `download_url`。

模型配置契约只包含供应商/模型标识、非敏感参数和 `secret_env_name` 引用。真实 API Key 由部署环境注入，不属于任何接口请求或响应。

`ModelProfilePreflightResponse` 用于启用前的无扣费基础预检，逐项报告适配器、参数、
密钥注入和必要的本机依赖是否就绪。它绝不返回密钥值、数据库连接信息或第三方原始错误。

`HealthResponse` 表示进程仍在运行；`ReadinessResponse` 额外返回已验证的依赖名称，
不会泄露数据库、Redis 或对象存储的连接细节。部署平台应将 `/ready` 配置为接收流量前的就绪探针。

前端只能依赖本目录定义的契约。数据库字段、第三方模型原始响应或内部错误堆栈均不得直接暴露给浏览器。
